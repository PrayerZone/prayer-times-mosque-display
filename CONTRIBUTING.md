# Contributing

Thank you for helping improve PrayerZone Mosque Display.

1. Open an issue for substantial behaviour or design changes.
2. Keep the application dependency-free unless a dependency has a clear,
   documented operational benefit.
3. Preserve accessibility, keyboard navigation, responsive layouts, and offline
   failure handling.
4. Run `npm run validate`.
5. Submit a focused pull request with screenshots for visual changes.

Do not include scraped schedules, private mosque data, tracking scripts, or
credentials. Translations and additional kiosk setup guides are welcome.
